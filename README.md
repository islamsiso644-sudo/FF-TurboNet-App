## 📱 التطبيق (APK)

| | |
|---|---|
| **اسم الحزمة** | `com.ff.turbonet` |
| **الحجم** | ~114 KB |
| **أندرويد** | 7.0 (API 24) وأحدث — يعمل على أغلب الأجهزة |
| **الأذونات** | الإنترنت فقط — لا يطلب شيئًا غريبًا |
| **اللغة** | عربي RTL كامل |

### الميزات
- 📡 **فحص البينق** — قياس زمن الوصول لكل سيرفرات فري فاير الحقيقية (14 سيرفرًا) بالتوازي، مع الترتيب والجيتر ونسبة الفقد
- 🌐 **اختبار DNS** — قياس 6 خوادم DNS (Cloudflare/Google/Quad9/OpenDNS) ببروتوكول DNS خام، مع إرشاد التغيير اليدوي
- 🚀 **تحسينات TCP/UDP** — 20 إعداد sysctl عبر su للأجهزة المروّتة (بافرات أكبر + Fast Open + SACK + F-RTO + Keepalive قوي)
- 🎮 **وضع اللعب** — إيقاف تطبيقات الخلفية الشهيرة قبل اللعب + تحسينات سريعة (لا يلمس أي لعبة أبدًا)
- 📊 **مراقبة حية** — بينق متجدد كل 2 ثانية على أسرع سيرفر مع ملخص إحصائي
- ↩️ **تراجع Undo** — إعادة كل الإعدادات الافتراضية بضغطة واحدة
- 📋 **نسخ + مشاركة** النتائج

### بدون روت
يعمل فحص البينق واختبار DNS والمراقبة والنسخ/المشاركة بدون روت. التحسينات العميقة تحتاج روتًا أو موديول Magisk المرفق.

## 🛡️ لماذا قانوني 100%؟
- ✅ يعدّل **إعدادات نظام الجهاز فقط** (sysctl / DNS / إيقاف تطبيقات الخلفية)
- ❌ لا يلمس ملفات اللعبة أو الذاكرة أو الباكتات
- ❌ لا يزوّر أو يعترض أي بيانات
- ❌ صفر ميزات غش — لا ESP، لا aimbot، لا تعديل جيتر أو حركة
- ✅ نفس فئة تحسينات "Gaming Mode" الرسمية من شركات الهواتف

> ⚠️ أي أداة تعدّل اللعبة نفسها (سكربتات هيدرا/بانجي/لاغ) = حظر مباشر. هذه الأداة **لا تفعل ذلك**.
